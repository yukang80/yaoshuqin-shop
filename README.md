# 姚舒琴的小食铺

HTML + CSS + JavaScript 单人经营小游戏，无需安装依赖，无广告，无外部素材请求。

## 在线试玩

[打开姚舒琴的小食铺](https://yukang80.github.io/yaoshuqin-shop/)

用小米手机或电脑浏览器打开上面的链接即可游玩，无需安装。

## 马上开始

双击 index.html，用浏览器打开。电脑可以用鼠标，手机可以用触屏。

1. 点击「开始营业」，每天经营 2 分钟。
2. 看顾客的图标订单，点击对应餐品制作。每次制作消耗少量食材金币。
3. 餐品完成后自动进入备餐区。顾客卡片变绿时，点击顾客上餐。
4. 赚金币升级设备、配方、座椅和装饰，或花 160 金币解锁拉面。
5. 每天接待 5 位客人得 35 金币；营业额达标再得 60 金币。

及时上餐会有小费和连单奖励。备餐最多每种 5 份，打烊时清空；金币与升级永久保留。低于 5 金币时可领取应急食材金，避免无法继续。

游戏支持暂停和音效开关。切换后台自动暂停，恢复后点击继续。营业中的进度每 2 秒自动保存，重新打开后先暂停，方便继续。

## 存档说明

进度只存在当前浏览器的本地存储里。不同浏览器、不同网址、本地文件和线上网址之间不会自动同步；浏览器清理数据可能丢失存档。请勿同时打开多个游戏窗口经营同一个存档。

## 手机使用

本版已做窄屏触摸布局；营业时客人区域会固定在上方，滑动制作区也能看到订单。尚未在真实小米手机上测试。

已经发布到 GitHub Pages，发布来源为 main 分支的根目录。更新游戏文件后，GitHub 会自动重新部署。

仓库：https://github.com/yukang80/yaoshuqin-shop

官方说明：https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

通过 HTTPS 访问时会缓存游戏文件，加载成功后可离线继续。是否可添加到手机桌面，取决于浏览器支持；SVG 图标的安装支持也可能因浏览器而异。

## 文件

- index.html：页面与原创矢量小店场景
- style.css：电脑和手机布局
- engine.js：经营规则
- game.js：操作界面、存档、音效
- manifest.webmanifest、sw.js、icon.svg：网页图标及离线支持

项目可直接作为 GitHub Pages 静态网站使用，不需要服务器或构建步骤。
