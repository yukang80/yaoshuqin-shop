# 霓港 · 自由街区

原创轻量 3D 城市沙盒，主角姚舒琴。纯 HTML、CSS、JavaScript / WebGL，无第三方库和外部资源。

手机：左侧摇杆移动/驾驶，滑动画面旋转视角，右侧挥拳、抢车、开火、换弹、疾跑/刹车。开火按住连续射击；前方目标辅助瞄准。绿色补给点恢复生命、维修车辆。

电脑：WASD/方向键移动，F 挥拳，E 上下车，空格开火，R 换弹，Shift 疾跑/刹车，Esc 暂停。

通过 HTTP 静态服务器运行，或部署到 GitHub Pages。首次加载后支持离线缓存。仅保存画质和声音设置，不保存当前游戏进度。

开局先选择姚舒琴的角色风格并换装：24 款上衣、16 款下装、10 款发型、12 双鞋、10 种配饰及 6 种肤色。穿搭在本机保存；暂停菜单可再次换装。
